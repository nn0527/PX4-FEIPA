# CH8 选择、CH12 启动与脱离

本分支侧吸来源 `124495ae80464e902e2c0ba7a7966731adb1058c`；顶吸来源 `6a8e0e38ffc866f20b3685883115ddbdd16ccd7f`。

CH8 低值（≤1200，上拨）选择顶吸，高值（≥1800，下拨）选择侧吸。CH12 第一次提交所选任务请求，保持阶段第二次请求脱离。动作期间 CH8 只选择下一轮，不切换当前任务或脱离目标。

- 侧吸：第一次 CH12 启动、第二次请求离墙，恢复稳定且原安全条件满足后自动交回 POSCTL，无第三次确认。CH8 选择侧吸后继续使用原侧吸入口检查，不因顶吸反馈缺失增加启动门槛。
- 顶吸：第一次 CH12 启动、保持时第二次请求脱离；融合高度下降并恢复稳定后锁定姿态，第三次 CH12 确认交回 POSCTL。
- CH12 去抖、回弹、断连重置及急停处理沿用原逻辑；网页与终端仍可指定任务。
- 侧吸定高服务、参数及页面保留。未引入斜面控制、侧吸第三次确认或遥控基础程序启停手势。

飞控失联保护节点沿用顶吸来源版本的地面参数写入与读回确认。它操作的是 PX4 全局参数，设置后侧吸的失联处理也会采用这些实际值。侧吸 ROS 控制参数未因此改值。
