# 斜面流程增量实现（test1019）

基线：6a8e0e3。仅变更 incline_attachment 独立模块、斜面配置和专项测试。

接近时使用 ENU 位置在启动航向上的投影，与顶部测距加高度拟合平面。至少 5 个新样本、8 cm 位移；姿态倾角超过 3 度、缺少雷达、拟合残差超过 5 mm 时拒绝估计。该估计假设机头正对平面，顶部雷达持续可见；不宣称达到文档的 ±3° 精度。估计无效时沿原有接触搜索运行。估计角度附近减速，仍以实际顶部接触判定为准，保留 8 秒预算。

接触稳定窗口记录实际倾角中位数，减去安装偏置，保存为本次 contact_angle；不跨板面自动复用。HOLD 仍冻结原姿态和推力。contact_pitch_bias_deg 是板面角度计算偏置，不改变接触姿态指令。

可选防滑模型：T/hover >= cos(alpha) + sin(alpha)/mu + normal_margin_ratio，其中 alpha 为板面对水平的夹角，mu 为台架标定的保守摩擦系数。假设推力标定近似线性、推力轴垂直板面。friction_coefficient 默认 0 表示未标定，不启用模型；不猜测实际摩擦或提高输出上限。估计推力超过上限或接触确认时推力不足，进入 ABORT 并请求自动降落；HOLD 不再使用防滑推力估计作为专项中止判据。

回平入口顶部距离 <=10 cm 时，将回平角速度上限降至 10°/s；保留末段制动、高度保持和超时保护。距离不等同于桨尖净空；实现前退再转需要桨盘几何和板面位姿，当前没有这些反馈，不能证明净空。禁止据此宣称实飞安全。

斜面准入要求相对解锁地面高度严格大于 0.10m，独立参数 /incline_attachment/min_entry_height_m；前距严格小于 2.0m、连续 0.4s 准入，前距 <=0.18m 进入慢速翻转，6.5cm 接触、0.2s 稳定保持。正常主动脱离仍回平、恢复并交回 POSCTL。顶吸/侧吸原有高度阈值保持。

上线前仍需标定推力上限、摩擦、安装偏置，验证雷达可见性与对坡航向，并完成无桨台架及实机测试。斜面现已按用户要求 enabled=true，flip_thrust_max=0.85，与侧吸总推力上限一致；该值不是新增实机标定结果。

## 测试模式选择

测试台新增顶吸/侧吸/斜面下拉框，仅切换操作面板，不发送飞行指令。执行中跟随实际任务并锁定选择；交回待命后可选择其他模式。反馈缺失时禁止切换。三个模式原有独立启动/脱离条件保留。

## 模式入口调整

CH8为两档开关，当前不参与模式选择。终端默认 console_mode_only=true，统一launch固定该设置，三种模式均由测试台选择并点击对应按钮启动。CH12待命时不启动默认任务；任务保持后仍可请求脱离，顶吸恢复后的CH12交回确认保留。CH8参数开关默认false，历史兼容路径保留但不在当前配置启用。该设置需重启基础程序加载；测试台只选择面板不会发出任务请求。

## 2026-11-05 斜面准入与故障降落

慢速翻转未接触时达到角度/推力上限、8秒超时或顶部测距失效，进入 LAND（映射公共 STATE_ABORT），置 abort_land_requested，由现有管理节点请求并确认 PX4 AUTO.LAND；斜面其他 ABORT 同样降落，不再先走受控回平。保留急停和飞手外部模式接管优先级，不自动重新进入旧任务。

## 2026-11-05 HOLD 姿态判据调整

HOLD 忽略顶部测距失效、距离超过8cm、角速度和可选防滑推力估计；相对接触锁定姿态的四元数夹角超过5度，立即 ABORT，不再等待0.3秒。接触确认阶段保留测距与稳定性检查。通用关键反馈有效性、推力输出边界、急停及飞手接管规则保留。任意执行阶段进入 ABORT 后均直接请求 AUTO.LAND，不先受控回平；正常主动脱离仍走 RETURN。

斜面回平末段制动起点调整为实测倾角 <=13°（detach_brake_target_deg=13.0）；近板回平限速与侧吸参数保持原值。

## 斜面雷达中断仅诊断（2026-11-05）

APPROACH 不再因前向断流中止；一帧有效前距 <=18cm 即触发 SLOW_FLIP，无连续距离确认，包含浮点消息边界容差。SLOW_FLIP 顶向断流仍继续有界接触搜索；不把无效/旧距离作为接触证据。CONTACT_SETTLE 顶向中断时暂停确认及其超时，保持姿态/推力，恢复后重新确认。HOLD、RETURN、RECOVER、EXIT 不因顶向/前向中断而 ABORT；原有姿态、输出、控制权、急停及接近/翻转/回平/恢复时间预算保持。雷达真实有效性及诊断信息不伪造，侧吸/顶吸逻辑未改。

验证：47项斜面逻辑、集成和控制台测试通过；未进行实飞验证。
