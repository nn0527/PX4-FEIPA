顶吸流程与遥控操作说明

模式只在测试台选择并使用对应按钮启动，CH8不参与；保持时可用CH12或对应脱离按钮请求脱离。提交顶吸请求后仍由飞手控制POSCTL，控制节点等待有效顶部测距及估计器、平衡基准等接管条件，不限制在1 m以内。接管后从当前高度按顶距闭环上升，最大目标速度0.15 m/s，接近顶部连续减速；有效顶距≤6.7 cm时直接使用保持推力0.55，停止主动上升，不因顶距更小而减推力；速度、姿态及新鲜距离反馈持续稳定后进入保持。保持推力目标0.55，保持时等待遥控器脱离请求；已发出的脱离请求或反馈异常时进入安全降落流程，以飞控实际模式确认。

脱离先请求机构释放，以脱离开始时的当前PX4融合高度锁定下降0.40 m目标，按剩余距离减速、速度PI调节推力，高度和速度连续稳定后恢复悬停；仅在DETACH阶段下降超过1.50 m时中止。高度与竖直速度采用 PX4 融合里程计，测距参与有效性检查，气压仅作辅助对照，不作为正常达标门槛。允许阶段摇杆可微调横滚/俯仰：人工修正时减弱位置回拉、暂停积分；回中后平滑恢复。恢复交回还需本轮遥控反馈有效、微调消退和位置权重恢复。恢复后保持高度与 XY 闭环，允许受限遥控修正；高度控制范围为目标 ±10 cm，交回允许 ±15 cm，并同时满足速度、姿态与连续稳定条件；恢复后再按 CH12 确认才请求交回，最终以飞控 POSCTL 及控制权释放确认完成。

侧吸流程与遥控操作说明

翻转、捕获、贴墙保持及大角度回正暂停树莓派水平闭环；回正末段实际倾角≤10°、角速度≤45°/s，收到新光流及水平估计连续有效≥0.30秒后恢复制动。实测总倾角≤5°、水平速度≤0.10 m/s、角速度≤10°/s持续1秒，且原恢复条件满足后请求POSCTL，实际确认后交接。固定右倾补偿取消，目标总倾角和变化率限制保留。光流失效暂停接近并报错；首次进入贴墙保持后暂停PX4光流和测距融合，离墙回平时实测总倾角≤80°请求恢复原值，等待读回和应用缓冲。目标限制不保证实际速度、倾角绝不超限。

斜面流程与操作说明

相对解锁地面高度>0.10 m、前距<2.00 m持续0.40秒等准入条件满足后低速接近，前距≤0.18 m开始慢速翻转；顶部测距≤6.5 cm时停止翻转与增推，接触稳定后进入 HOLD，保持姿态与推力。估计无效时继续接触搜索，以实际接触判据为准。

HOLD 时点击斜面脱离，受控回平并保持高度，恢复悬停稳定后请求交回 POSCTL；只有飞控实际确认、输出归属释放才显示交回完成。斜面使用独立参数，当前推力上限0.85。流程以实时控制节点反馈为准。

基础程序不会自动解锁或起飞。动作以控制节点反馈为准。
