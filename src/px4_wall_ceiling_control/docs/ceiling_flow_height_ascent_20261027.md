# 顶部初始基准 + 朝下光流测距接近

> 2026-10-28 更新：吸顶已删除“真实顶部雷达 + 低通”的普通模式，本文件的基准+光流测距成为**唯一**顶距来源，`approach_flow_height_enabled` / `closed_loop_approach_enabled` 开关随之移除。

控制台入口 `wall_console_flight.launch` 开启 `approach_flow_height_enabled`。旧入口默认关闭，原顶部持续测距分支不变。
## 控制与基准

- 进入 CEILING_ARMED 时要求有效顶部测距、有效朝下光流测距及原有运动/飞控准入条件。顶部接收时间与光流源时间差最多 0.20 秒，光流与姿态时间差最多 0.20 秒。
- 锁定初始竖直顶部距离 d0 和初始离地高度 h0。离地高度 h 使用 `/mavros/px4flow/raw/optical_flow_rad.distance`，按机体 z 轴与 ENU 竖直夹角投影。
- 剩余顶部竖直距离为 `d = d0 - (h - h0)`。现有距离比例/制动速度限制继续生成上升速度目标，内层仍使用 PX4 融合里程计的垂直速度反馈，不对测距求导替换速度反馈。
- 基准锁定后，新的顶部数据及顶部健康状态均不再参与本轮距离控制，不会因顶部过期而暂停或中止，也不能重写基准。
- 接近、接触推力调整、稳定判定及接触丢失检测使用基准估算的距离。接触稳定要求独立的新光流与里程计样本，定时器或重复源时间戳不能确认稳定。
- 为兼容现有消息与记录器，`ceiling_distance_raw_m` / `ceiling_distance_filtered_m` 在此模式锁定后承载基准估算的轴向顶部距离，并非顶部雷达实测；`reason` 明确注明“顶距来源：接管基准－朝下光流测距升高量（固定平面地面）”。原始光流测距仍记录在原光流话题中。
- 回到 NORMAL_FLIGHT 后丢弃基准，下一轮必须重新取得有效顶部测距，不复用上轮数据。原有脱离/恢复高度反馈逻辑不变。

## 有效性与失效保护

- 光流必须通过既有质量、积分、数值、接收时间、源时间递增/过期/时钟跳变检查。额外检查 MAVLink `time_delta_distance_us`，新光流包携带过期距离也不能刷新高度。
- 默认朝下距离范围 0.02–6.0 米；这只是软件边界，不表示传感器经过此量程验证。参数为 `approach_flow_min_m` / `approach_flow_max_m`，需与实际传感器规格和验证量程一致。
- 姿态必须处于既有倾角边界内。单帧高度变化超过 `0.25 + 2*dt` 米时锁存基准异常并中止，防止明显地面突变/跳读驱动继续接近。
- 朝下测距或其他必要反馈不可用时，立即给出零接近速度目标；持续丢失沿用 2 秒失效时限。基准模式的 HOLD 同样保留朝下距离丢失看门狗，不继承上升任务期限。
- 时间、行程、倾角、急停、估计器、飞控及控制链路保护继续生效；估算已越过锁定天花板平面时直接锁存中止。

## 几何适用条件与验证范围

此估算依赖静止、连续的平面地面和天花板，朝下传感器沿机体负 z 轴安装，传感器相对机体安装固定。横向经过不同高度物体、地面斜坡、顶部高度变化或基准测量误差，都会影响距离估算；它不能独立证明实体接触、吸附或实际压缩量。已有机构输出关闭配置不变。
