## 遥控操作

| 条件 | CH8 / CH12 |
| --- | --- |
| 启动前 | CH8低值≤1200选顶吸，高值≥1800选侧吸；CH12需稳定回低位后重新拨高 |
| 已解锁，侧吸 | 第一次CH12启动侧吸，WALL_HOLD后第二次请求脱离；恢复稳定并通过原检查后自动POSCTL交回，无第三次确认 |
| 已解锁，顶吸 | 第一次CH12启动，SURFACE_HOLD后第二次请求脱离；融合高度下降并恢复锁定后第三次确认交回POSCTL |
| 动作期间切换CH8 | 只改变下一轮选择，不能把本轮脱离发给另一任务 |
| 未解锁且反馈新鲜 | CH12一次有效回弹脉冲停止基础链路；不会作为飞行动作使用 |

## 基础链路启动与停止

网页保留一键配置并启动和停止基础链路；不会自动解锁或起飞。
`shared_bridge.serve()`启动时调用源版`rc_startup.install(broker)`加载监听。监听自动维护最小ROS/MAVROS遥控通信，完整控制、雷达和记录仍需网页启动或物理组合动作。
启动要求新鲜连接/未解锁/遥控数据、解锁开关CH6低位、急停CH7未触发，并读回核验通道映射和摇杆解锁冲突。先在低油门下回中一次，再按源版AT9S组合保持约2秒（通道条件CH1<1200、CH2>1800、CH3<1200、CH4>1800）。
启动、网页启停及遥控CH12停止共用后端锁；停止会取消未完成启动线程，防止停止后又被旧启动拉起。正常停止保留健康MAVROS和监听，停止控制/雷达/记录；地面重启MAVROS仍走完整清理。清理失败禁止自动重启。
启动配置保留本分支共享悬停推力0.49，不采用源版配置文件中的0.48。未安装或修改树莓派systemd服务；加载监听不等于已完成开机部署。

## 侧吸失联处理

- 网页或浏览器断线：不直接中止ROS飞行程序，原任务与日志继续，断线不重放网页动作。
- ROS/MAVROS/树莓派导致OFFBOARD输出流中断：依赖飞控内部OFFBOARD失联保护，目标COM_OBL_RC_ACT=4、COM_OF_LOSS_T=2.0、旧固件需要时COM_OBL_ACT=0。由源版保护节点在连接且未解锁时写入，并新鲜读回核验；这是全局设置，顶吸、侧吸都受影响。
- 遥控消息或急停反馈不再新鲜：原急停数据守卫阻止ROS输出，随后OFFBOARD流失联由PX4处理。RC链路独立失联动作仍取决于飞控现有RC失联参数，本次没有设置NAV_RCL_ACT或COM_RC_LOSS_T。
- 侧吸普通ABORT保留原恢复/高度控制/交回流程，不是一律AUTO.LAND。脱离轨迹结束俯仰为负的分支仍请求AUTO.LAND。

具体飞控动作以实际固件、读回参数、飞控状态及受控验证为准；本地测试不能证明真实失联降落已生效。

## 网页权限与地址

`safe_transfer`只决定网页客户端何时能取得/释放操作权限，不负责切换飞控模式。源版默认允许满足其余检查的POSCTL；若新鲜运行配置明确侧吸使用ALTCTL，也允许ALTCTL。仍要求有效飞控反馈、无启动过程、未解锁，或已解锁时IDLE/LOCKED且输出归属为0；不允许在动作中转移。
定高页面、参数、HTTP路由、动作白名单及ROS服务均已移除；未加入斜面。
动态主机白名单保留显式配置的主机，并按需以2秒缓存间隔发现本机IPv4接口地址；旧自动发现地址可过期。仅接受正确端口、原有Origin/CSRF/会话检查，非任意外部IP。离线模拟不进行本机网络地址发现。
