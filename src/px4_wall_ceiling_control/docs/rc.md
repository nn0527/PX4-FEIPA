# 遥控器：任务选择、启停、修正与接管

本文汇总 AT9S Pro 的通道分配、`CH8`/`CH12` 任务操作、未解锁启动手势、`CH12` 停止
基础链路、遥控姿态修正与一键接管。

- 操作门：`scripts/operator/terminal_operator_node.py`
- 启动绑定：`src/px4_wall_ceiling_control/rc_startup.py`、`config/rc_startup.json`
- 接管适配：`src/px4_wall_ceiling_control/adapters/rc_takeover.py`
- 接管入口：`scripts/operator/rc_takeover.py`

## 1. 实测通道分配

| 通道 | 用途 | 说明 |
|---|---|---|
| `CH1`–`CH4` | 摇杆 | 启动手势与回中检查使用 |
| `CH5` | 飞行模式 | 需能进入 `ALTCTL` / `POSCTL` |
| `CH6` | 解锁开关 | `MAN_ARM_GESTURE=0`，由开关解锁 |
| `CH7` | 急停 | 与程序急停判据独立 |
| `CH8` | 任务选择 | 低值（≤1200，上拨）顶吸；高值（≥1800，下拨）侧吸 |
| `CH12` | 启动/脱离/停止 | 瞬时开关，低值静止、高值按下 |

参数命名空间：`/terminal_operator_node`（通道索引从 0 开始，`CH8`=7、`CH12`=11）。
`rc_mode_up_is_high` 必须与发射机标定一致（本机为 `false`）。

## 2. CH8 / CH12 任务操作

- `CH8` 只在待命期选择下一轮任务；动作期间拨动不切换当前任务、不改变脱离目标。
- `CH12` 第一次提交所选任务请求，保持阶段第二次请求脱离。
- 侧吸：第一次 `CH12` 启动，第二次请求离墙；恢复稳定且原安全条件满足后**自动**交回
  -- 终端入口回 `ALTCTL`，测试台入口回 `POSCTL`；没有第三次确认。
- 吸顶：第一次启动，保持时第二次请求脱离；融合高度下降并恢复稳定、锁定姿态后，
  需要**第三次** `CH12` 才请求 `POSCTL`。
- 去抖：`MomentarySwitch` 0.05 s 去抖、0.5 s 断连重置，低电平先武装再等待上升沿；
  重复或迟到脉冲不会排队到下一轮，也不会仅因重复触发降落。
- 网页与 `/attachment/terminal_command` 终端命令仍是等价的第二入口。
- 动作完成后必须先释放开关，再开始下一轮，避免高电平自动重复翻转。

## 3. 急停

- `CH7` 由飞控自身处理；程序的 `kill_guard_enabled` 额外读取飞控参数
  `RC_MAP_KILL_SW`、`RC_KILLSWITCH_TH`、`RC%d_MIN/MAX/REV` 生成
  `/attachment/kill_switch`（JSON：`valid`/`active`/`channel`）。
- 急停生效或反馈无效时，操作门立即释放当前意图；输出端与模式管理器独立复核。
- 反馈超过 0.35 s 未更新视为无效，按“不可用”处理，而不是“未触发”。

## 4. 遥控姿态修正（由唯一输出节点执行）

- `attachment_output_mux_node` 直接订阅 `/mavros/rc/in`，以 50 Hz 发布姿态目标，
  不经 10 Hz 操作门。
- 通道索引由 `/attachment_output_mux_node/rc_roll_channel_index` 等参数给出；
  测试台入口启用：吸顶横滚/俯仰，侧吸横滚/偏航。
- 限幅：自由飞行每轴 8°（吸顶专项参数 5°）、接触 2°；侧吸脱离旋转默认横滚 2°、
  俯仰 0°。先限幅再限变化率，最终仍受总倾角与推力轴速率限制。
- `/attachment/rc_preview_deg` 输出计划修正角度，可用于观察模式逐杆核对；
  `/attachment/rc_input_age_ms` 只表示 ROS 收到 RC 到发布设定值的年龄，
  `-1` 表示无效/超时，不包含飞控与 PX4 响应延迟。
- RC 输入过期时修正渐退到零，模式交接被阻止；飞手仍可直接用模式开关请求 `ALTCTL`。
- 需确认 PX4 `COM_RC_OVERRIDE` 不会在修正摇杆时意外退出 OFFBOARD。

## 5. 未解锁启动手势

作用：飞控未解锁时用摇杆组合启动整套基础链路（不含解锁、起飞、模式切换与吸附动作）。

1. 保持飞控未解锁，`CH6` 解锁开关置低、`CH7` 急停未触发，油门最低。
2. 将左右方向及右杆上下回中一次。
3. 左杆右下、右杆左下，同时保持约 2 秒（实测：`CH1<1200`、`CH2>1800`、`CH3<1200`、`CH4>1800`）。
4. 提示音：接受短响一声；全部就绪短响两声；失败长响一声。再次触发前必须回到中位；
   油门不需要回中。

安全条件：飞控连接有效、未解锁、遥控数据有效、解锁开关低位、急停未触发、处于普通
手动模式。开机或失联恢复时若摇杆已在组合位置，必须先退出再重做，不能自动重放。

程序在连接后定期核对飞控参数（解锁方式、解锁/急停/模式通道等），执行启动前再核对
一次；关键配置变化或读取失败时禁止遥控启动，不自动修改飞控参数。提示音通过
`/mavros/play_tune` 请求。

启动范围：只拉起与页面相同的 `RemoteRuntime.start(config)`，保存配置为
`/dev/serial/by-path/wall-fcu`（230400）、`wall-top`、`wall-front`、`hover_thrust=0.49`、
普通实飞配置。`config/rc_startup.json` 中 `enabled=true`、`stop_ch12_enabled=true`。

## 6. CH12 停止基础链路

- 条件：飞控未解锁且飞控/遥控反馈有效。每次有效脉冲只停止一次，不按奇偶切换。
- 停止成功短响三声；保留 ROS master、MAVROS 与遥控监听，可立即重新用启动手势拉起。
- 飞控已解锁时该功能完全禁止，`CH12` 仍归吸附/脱离逻辑。
- 开机、失联恢复、从已解锁变为未解锁时，若 `CH12` 正停留在触发电平，不会补发停止。
- 与页面“停止基础链路”共用同一后端方法与锁，不获取页面控制权；启动过程中的停止会
  取消启动并核验启动线程退出。
- 停止清理失败时监听保持禁止，需先解决残留进程或串口占用；地面恢复 MAVROS 期间
  不接受遥控启动。

错误恢复边界：

- 业务节点残留但 MAVROS/遥控正常 → `CH12` 停止后重新启动。
- MAVROS 退出或无响应、反馈过期 → 不能用缓存的未解锁状态授权清理；确认落地、
  未解锁、电机停止后在页面执行停止或地面恢复。

## 7. 一键遥控器接管

适用：仍已解锁、处于 OFFBOARD 的吸顶/侧吸控制，包括 ABORT/FAULT。

```bash
rosrun px4_wall_ceiling_control rc_takeover.py
# 或
rosservice call /attachment/rc_takeover "{}"
```

流程：

1. 检查输出已启用、飞控已连接/解锁且为 OFFBOARD、急停未生效、姿态与 RC 新鲜；
   从 PX4 读取四轴 RC 映射、校准与反向，油门用校准上下限中点作为中位。
2. 模式管理器进入 `RC_TAKEOVER`，清除旧吸附意图，禁止自动重新进入 OFFBOARD；
   原输出流持续到管理器确认。
3. 首帧姿态取实测四元数，推力取最近 0.3 s 内实际发布值；姿态按最短路径 20°/s、
   推力变化 ≤0.15/s、单步 ≤0.05 s。没有新鲜推力起点时拒绝继续。
4. 过渡期间摇杆实时生效：横滚/俯仰 ±10°、偏航 ±20°/s、油门映射竖直速度 ±0.5 m/s，
   并保留原推力上下限。过渡 ≥2 s，且指令与摇杆目标差 <2°、实测姿态差 <5°、
   竖直速度差 <0.2 m/s、推力差 <0.02，连续 0.5 s 后允许模式交接。
5. 恢复进入 OFFBOARD 前记录的 `ALTCTL`/`POSCTL`；交接仍要求有效估计器与融合恢复确认，
   `POSCTL` 还要求水平位置与速度估计有效。模式请求失败按原重试间隔重试。

边界：返回成功只表示请求被接受，最终以 `/mavros/state` 为准；接管中途 RC、姿态、
飞控或管理器反馈失效、急停生效时立即停止并锁存失败，不会自动续接。过渡是有界
RC 姿态/竖直速度控制，不等同于复现 PX4 原生控制器，切换瞬间可能有差异。本功能
不解除机械吸附、不解锁、不主动进入 OFFBOARD。

## 9. 未验证

- 真实发射机的组合手势、通道索引、正反方向与中位必须在现场逐杆核对；参数错误会
  使节点拒绝启动（索引缺失或重复时启动失败）。
- 接管过渡的实际无扰程度、PX4 `POSCTL` 摇杆尺度差异需在台架与实飞确认。
- 失联动作 (`COM_OF_LOSS_T`、`COM_OBL_RC_ACT`) 由 `ceiling_failsafe_guard_node`
  在飞控连接且未解锁时写入并读回核验，见 [ceiling](ceiling.md) 第 5 节。
